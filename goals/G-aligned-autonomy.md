# G-aligned-autonomy — Agents build unattended within recorded boundaries

## Statement

Operators trust agents to do real work unattended because every
boundary is recorded, every gate holds, and every claim carries
proof.

## Measure

A full loop — pick up a queued item, implement, verify, evidence,
integrate, complete — runs unattended in an external repo with every
gate green and evidence bound.
