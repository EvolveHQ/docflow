# docflow

Documentation-led development for coding agents: scaffold repository conventions,
record decisions, plan and ship work, and coordinate portable workspaces.
Fourteen skills share the same templates and workspace assets across supported hosts.

## Install

In Claude Code:

```text
/plugin marketplace add EvolveHQ/docflow
/plugin install docflow@evolvehq
```

For pi and omp, install the npm package `@evolvehq/docflow`. For Codex and the
other supported hosts, follow the [installation guides](https://evolvehq.github.io/docflow/).
