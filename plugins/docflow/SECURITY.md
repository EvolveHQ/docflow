# Security guidance

## Reporting a concern

Use the project's published contact, [docflow@evolvehq.io](mailto:docflow@evolvehq.io),
to contact the maintainers about a suspected vulnerability. This is the existing
[project contact](https://evolvehq.github.io/docflow/privacy/), rather than a
dedicated security inbox. GitHub private vulnerability reporting is currently
not enabled for this repository.

Describe the affected version or commit, host, impact and steps to reproduce in
a disposable test repository. Do not send credentials or private repository
contents. Avoid posting sensitive exploit details in public issues.

## Support and limits

No security response SLA, bounty programme or supported-version maintenance
schedule is promised. Include your exact installed version; older versions
have no stated security backport commitment.

Docflow supplies skills, templates and workspace tools that run through the
coding host you select. Review proposed changes and configure that host's
permissions and isolation for your repository. Hostless checks do not establish
native-host security or guarantee that an agent will obey every instruction.
