# Goals

The active goals this repository serves — the top of the traceability
chain (goal → record → criterion → plan → evidence). Single file on
purpose: small enough to load in full before any task; the value of a
goal, like a constraint, is that it is always in view.

Guide: **3–7 Active goals.** Growth past the cap is a signal the audit
reports, not a limit anything enforces. Goal ids are **stable and
never reused**; a finished or abandoned goal keeps its entry under a
terminal state — removal is by state, never by deletion.

Entries are written by the brainstorm skill on operator approval — an
approved outcome-class candidate becomes an entry here.
