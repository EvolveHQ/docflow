# Goals

The active goals docflow serves — the top of the traceability chain
(goal → record → criterion → plan → evidence). Single file on
purpose: loadable in full before any task. Guide: 3–7 Active goals;
ids are stable and never reused; removal is by terminal state, never
deletion. Entries are written by the brainstorm skill on operator
approval.

## G-aligned-autonomy — Agents build unattended within recorded boundaries
- state: Active
- statement: Operators trust agents to do real work unattended because
  every boundary is recorded, every gate holds, and every claim
  carries proof.
- measure: A full loop — pick up a queued item, implement, verify,
  evidence, integrate, complete — runs unattended in an external repo
  with every gate green and evidence bound.
- horizon: 2026-Q4
- review-by: 2026-10-31

## G-external-adoption — docflow drives repos beyond its own
- state: Active
- statement: The conventions run real repositories other than this
  one.
- measure: At least three external repos bootstrapped or retrofitted
  and actively shipping under the conventions (currently one).
- horizon: 2027-Q1
- review-by: 2026-12-31

## G-one-zero — A published 1.0 gated by behavioural evals
- state: Active
- statement: docflow 1.0 is published, with the behavioural eval
  suite as its release gate.
- measure: v1.0.0 tag and npm publish with the behavioural suite
  green at the release commit; publication itself only on explicit
  operator instruction.
- horizon: 2026-Q4
- review-by: 2026-11-30
